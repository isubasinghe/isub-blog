Hindler-Milner type system

Basic idea

A polymorphic type system that admits principal types and full type inference without annotations (Algorithm W). Foundation of ML, Haskell, OCaml.

Key formulas

  • Typing rule (Var): x:σ∈ΓΓ⊢x:inst(σ)\dfrac{x : \sigma \in \Gamma}{\Gamma \vdash x : \mathrm{inst}(\sigma)}Γ⊢x:inst(σ)x:σ∈Γ​
  • Typing rule (Abs): Γ,x:τ1⊢e:τ2Γ⊢λx.e:τ1→τ2\dfrac{\Gamma, x:\tau_1 \vdash e : \tau_2}{\Gamma \vdash \lambda x.e : \tau_1 \to \tau_2}Γ⊢λx.e:τ1​→τ2​Γ,x:τ1​⊢e:τ2​​
  • Generalisation: gen(Γ,τ)=∀αˉ. τ\mathrm{gen}(\Gamma, \tau) = \forall \bar\alpha.\ \taugen(Γ,τ)=∀αˉ. τ where αˉ=ftv(τ)∖ftv(Γ)\bar\alpha = \mathrm{ftv}(\tau) \setminus \mathrm{ftv}(\Gamma)αˉ=ftv(τ)∖ftv(Γ)
  • Algorithm W: type inference via unification; produces principal type.
  • Let-polymorphism only — no first-class polymorphism (system F is needed for that).
