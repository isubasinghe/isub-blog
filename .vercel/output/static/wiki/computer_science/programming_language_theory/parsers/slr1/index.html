SLR(1) parser

Basic idea

Simple LR(1): an LR(0) automaton augmented with FOLLOW-set lookahead — reduce by A→αA \to \alphaA→α only when the next token is in FOLLOW(A)\mathrm{FOLLOW}(A)FOLLOW(A). Stronger than LR(0), weaker than LALR(1), cheap to construct.

Key formulas

  • Parse time: O(n)O(n)O(n)
  • Reduce on A→αA \to \alphaA→α allowed iff lookahead ∈FOLLOW(A)\in \mathrm{FOLLOW}(A)∈FOLLOW(A).
  • Power: LR(0) ⊊\subsetneq⊊ SLR(1) ⊊\subsetneq⊊ LALR(1) ⊊\subsetneq⊊ LR(1).
