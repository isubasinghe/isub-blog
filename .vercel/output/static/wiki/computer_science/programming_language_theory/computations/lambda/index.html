lambda

Basic idea

The λ\lambdaλ-calculus: a minimal formal system of variables, abstraction λx. e\lambda x.\, eλx.e, and application e1 e2e_1\, e_2e1​e2​. Turing-complete in three rules; the theoretical core of every functional language.
