Single Static Assignment (SSA) form

Basic idea

An IR in which every variable is assigned exactly once. Joins in control flow are bridged by ϕ\phiϕ-functions that pick a value based on which predecessor block executed. SSA exposes data-flow directly and makes most optimisations linear.

Key formulas

  • ϕ\phiϕ-function: x3=ϕ(x1,x2)x_3 = \phi(x_1, x_2)x3​=ϕ(x1​,x2​) at a join from blocks B1,B2B_1, B_2B1​,B2​.
  • Dominance frontier DF(B)DF(B)DF(B): nodes where BBB does not strictly dominate but does dominate a predecessor — places where ϕ\phiϕ-nodes are inserted.
  • Cytron et al.’s algorithm: linear in size of dominance frontiers.
