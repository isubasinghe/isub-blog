semantics

Basic idea

Formal meaning of programs. Three classical styles: operational (how it runs, step-by-step), denotational (what mathematical object it denotes), axiomatic (which logical properties hold).

Key formulas

  • Small-step: e→e′e \to e'e→e′
  • Big-step: e⇓ve \Downarrow ve⇓v
  • Denotational: ⟦e⟧:Env→Val\llbracket e \rrbracket : \text{Env} \to \text{Val}[[e]]:Env→Val
  • Hoare triple (axiomatic): {P} C {Q}\{P\}\ C\ \{Q\}{P} C {Q}
