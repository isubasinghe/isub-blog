k-d Tree

Basic idea

A BST over kkk-dimensional points that cycles the splitting axis at each level. Good for nearest-neighbour and range queries in low dimensions; degrades badly as kkk grows (“curse of dimensionality”).

Key formulas

  • Build: O(nlog⁡n)O(n \log n)O(nlogn)
  • Range / nearest-neighbour search: O(n)O(\sqrt n)O(n​) in 2D balanced, O(n1−1/k+r)O(n^{1-1/k} + r)O(n1−1/k+r) general worst case
  • Effective only while k≲20k \lesssim 20k≲20.
