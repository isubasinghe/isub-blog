Succint Datastructures

Basic idea

Data structures whose space usage is information-theoretically optimal plus a lower-order term, while still supporting fast queries. Example: a bit-vector with rank/select in O(1)O(1)O(1) using n+o(n)n + o(n)n+o(n) bits.

Key formulas

  • Succinct: space =Z+o(Z)= Z + o(Z)=Z+o(Z) where ZZZ is the information-theoretic lower bound
  • Compact: O(Z)O(Z)O(Z) bits
  • rank/select on bit-vectors: O(1)O(1)O(1) time, o(n)o(n)o(n) extra bits
