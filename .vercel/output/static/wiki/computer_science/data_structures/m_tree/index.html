M Tree

Basic idea

A balanced tree for similarity search in generic metric spaces (any distance satisfying the triangle inequality), not just Euclidean. Stores routing objects with covering radii so the triangle inequality can prune subtrees during search.

Key formulas

  • Triangle inequality: d(x,z)≤d(x,y)+d(y,z)d(x,z) \le d(x,y) + d(y,z)d(x,z)≤d(x,y)+d(y,z)
  • Pruning rule: skip subtree at routing object rrr with radius ρ\rhoρ if d(q,r)>ε+ρd(q, r) > \varepsilon + \rhod(q,r)>ε+ρ for ε\varepsilonε-range query.
  • Range / kNN query: O(log⁡n)O(\log n)O(logn) in low intrinsic dimension.
