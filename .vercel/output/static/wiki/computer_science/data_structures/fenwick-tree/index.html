Fenwick tree

Basic idea

Binary-indexed tree: an array that supports prefix-sum queries and point updates in O(log⁡n)O(\log n)O(logn) using bit tricks on the index. Smaller and faster constants than a segment tree when only prefix sums are needed.

Key formulas

  • Update index iii: i+=i&−ii \mathrel{+}= i \mathbin{\&} -ii+=i&−i
  • Query prefix sum up to iii: i−=i&−ii \mathrel{-}= i \mathbin{\&} -ii−=i&−i
  • Range sum [l,r][l,r][l,r]: prefix(r)−prefix(l−1)\text{prefix}(r) - \text{prefix}(l-1)prefix(r)−prefix(l−1)
  • Time: O(log⁡n)O(\log n)O(logn) per op; Space: O(n)O(n)O(n)
