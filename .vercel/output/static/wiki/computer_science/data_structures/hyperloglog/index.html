HyperLogLog

Basic idea

A streaming cardinality estimator that uses O(log⁡log⁡n)O(\log\log n)O(loglogn) bits per register. Hash each element, take the position of the first 1-bit in the low bits as a proxy for log⁡2\log_2log2​ of the (sub-stream) cardinality, then average across mmm registers with the harmonic mean.

Key formulas

  • Estimate: n^=αm⋅m2⋅(∑j=1m2−Mj)−1\hat n = \alpha_m \cdot m^2 \cdot \left(\sum_{j=1}^{m} 2^{-M_j}\right)^{-1}n^=αm​⋅m2⋅(∑j=1m​2−Mj​)−1
  • Standard error: σ≈1.04/m\sigma \approx 1.04/\sqrt{m}σ≈1.04/m​
  • Constant: α16=0.673, α32=0.697, α64=0.709, αm→1/(2ln⁡2)\alpha_{16}=0.673,\ \alpha_{32}=0.697,\ \alpha_{64}=0.709,\ \alpha_m \to 1/(2\ln 2)α16​=0.673, α32​=0.697, α64​=0.709, αm​→1/(2ln2)
