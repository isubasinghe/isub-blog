Bloom filter

Basic idea

A probabilistic set: tells you whether an element is possibly in the set or definitely not. Uses kkk hash functions to set bits in an mmm-bit array. Cannot have false negatives; false-positive rate is tunable.

Key formulas

  • False-positive rate: p≈(1−e−kn/m)kp \approx \left(1 - e^{-kn/m}\right)^kp≈(1−e−kn/m)k
  • Optimal kkk: k∗=(m/n)ln⁡2k^* = (m/n)\ln 2k∗=(m/n)ln2
  • Bits per element for FP rate ppp: m/n=−log⁡2p/ln⁡2≈1.44log⁡2(1/p)m/n = -\log_2 p / \ln 2 \approx 1.44 \log_2(1/p)m/n=−log2​p/ln2≈1.44log2​(1/p)
