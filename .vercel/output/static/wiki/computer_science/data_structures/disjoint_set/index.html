Disjoint Set

Basic idea

Union-find: tracks a partition of a set under merge (union) and lookup-root (find). With union-by-rank plus path compression, both operations run in inverse-Ackermann amortised time — essentially constant.

Key formulas

  • Amortised time per operation: O(α(n))O(\alpha(n))O(α(n)) with union-by-rank + path compression
  • Sequence of mmm ops on nnn elements: O(m α(n))O(m\,\alpha(n))O(mα(n)) total
  • Without optimisations: O(log⁡n)O(\log n)O(logn) per op
