Count-min sketch

Basic idea

Probabilistic frequency estimator. A d×wd \times wd×w array of counters, each row indexed by a different hash function: increment all ddd cells on update, return the minimum on query. Always overestimates; never undercounts.

Key formulas

  • Estimate: f^x=min⁡i=1..dCM[i,hi(x)]\hat f_x = \min_{i=1..d} CM[i, h_i(x)]f^​x​=mini=1..d​CM[i,hi​(x)]
  • Width: w=⌈e/ε⌉w = \lceil e/\varepsilon \rceilw=⌈e/ε⌉
  • Depth: d=⌈ln⁡(1/δ)⌉d = \lceil \ln(1/\delta) \rceild=⌈ln(1/δ)⌉
