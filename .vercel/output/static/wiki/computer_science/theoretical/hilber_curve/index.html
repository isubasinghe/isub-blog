Hilbert Curve

Basic idea

A continuous space-filling curve that maps [0,1][0,1][0,1] onto [0,1]d[0,1]^d[0,1]d while preserving locality: points close on the curve are close in space. Useful for spatial indexing and cache-friendly traversals.

Key formulas

  • Recursively defined; at iteration nnn the curve visits 4n4^n4n cells (in 2D) of side 2−n2^{-n}2−n.
  • Distance on curve ↔ spatial distance bound: ∥p−q∥2≤c⋅dH(p,q)1/d\|p - q\|_2 \le c \cdot d_H(p,q)^{1/d}∥p−q∥2​≤c⋅dH​(p,q)1/d
  • Length of nnn-th order approximation: Ln=2n−2−nL_n = 2^n - 2^{-n}Ln​=2n−2−n (unit square).
