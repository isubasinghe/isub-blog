Transivity

Basic idea

A relation is transitive if relating aaa to bbb and bbb to ccc forces aaa related to ccc. One of the three defining properties of an equivalence relation and of a partial order.

Key formulas

  • ∀a,b,c∈X.  (R(a,b)∧R(b,c))⇒R(a,c)\forall a,b,c \in X.\; (R(a,b) \land R(b,c)) \Rightarrow R(a,c)∀a,b,c∈X.(R(a,b)∧R(b,c))⇒R(a,c)
  • Equivalently: R∘R⊆RR \circ R \subseteq RR∘R⊆R

A homogeneous relation R over set X is transitive if for all elements a,b,c in X whenever R relates a to b and b to c, then R also relates a to c.
