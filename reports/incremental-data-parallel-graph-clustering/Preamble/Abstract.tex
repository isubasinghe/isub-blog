\abstract{
\addtocontents{toc}{\vspace{1em}}  % Add a gap in the Contents, for aesthetics
    Community extraction has become a fundamental operation in numerous real world applications.  
    We propose a simple modification to the traditional Louvain method \cite{blondel2008fast} that is used for the detection of community structures in large networks. 
    The modification is aimed to enable parallel and incremental processing of network structures, such that 
    the algorithm can be applied in stream processing settings. 
}
